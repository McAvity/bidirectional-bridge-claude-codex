# W22-03: Instalacja obok starego wydania i migracja projektu

Status: planned — Gate 1 pending.
Feature: [brief](../docs/features/F-W22-hcom-native/brief.md).
Design: [plan](../docs/features/F-W22-hcom-native/design.md).
Dependencies: W22-01, W22-02.
Format: Markdown work-items; Yumi CLI nieobecne.

## Wynik i zakres

Wdrożyć uzgodniony lifecycle CLI wykorzystując istniejący store. install nie dotyka locków, runtime, DB ani procesów; żadnego automatycznego GC. migrate ma plan/diff, sprawdzenie pochodzenia danych, odczyt nierozliczonej pracy, rozpoznanie własnych wpisów Codex/Claude, backup i resumable apply. Nie usuwać user config/globalnych pluginów/baz. Używać wyłącznie zakresowej obserwacji starego MCP na etapie migracji, nigdy kontroli native writerów. status/doctor odróżnia installed/selected od observed, raportuje activation unknown gdy brak dowodu. Odmowa migracji nie cofa udanej instalacji.

Punkty startowe: scripts/workflow-source; scripts/setup/common.mjs, workspace.mjs i diff.mjs jako wzorce, bez bezrefleksyjnego wywołania planChange/findActiveUse; scripts/upgrade-local.mjs pozostaje legacy.

## Odbiór i dowody

Pokrycie: AC-02, AC-03, AC-04, AC-05, AC-06, AC-07, AC-08.
Powtórzona instalacja/migracja jest no-op; zmienione wejścia, custom MCP, foreign DB, aktywna praca, interrupted apply i nieznany stan dają właściwe diagnozy. Test instalacji z rzucającymi atrapami wszystkich legacy probes. Brak modyfikacji hcom state; dwa projekty niezależne; test realnych lokalnych procesów dla migracji bez modeli.

Ledger podczas wykonania: `docs/features/F-W22-hcom-native/execution/W22-03/01.md`.

## Własność i stop

Nowy lifecycle i minimalne moduły migracyjne/testy; nie zmieniać silnika runtime ani globalnego środowiska. Koordynator utrzymuje index/decyzje/statusy, wykonawca nie rozszerza ich zakresu.
Dostawa: konkretne BASE/HEAD, zakres zmian, komendy/wyniki i ograniczenia.
Bez push/publikacji/migracji użytkowych projektów i zmian nadzorującego runtime.
Sprzeczność z briefem lub konieczność większego budżetu wymaga konkretnej decyzji;
zwykłe korekty zgodnego zachowania pozostają w tej samej zgodzie wykonawczej.
