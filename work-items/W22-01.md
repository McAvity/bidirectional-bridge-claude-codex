Zamrozić contracts/01-lifecycle.md: tryby projektu, schema znacznika, CLI status/install/migrate/doctor, kody wyników i rozdzielenie installed/selected/activation/migration. Opisać źródło wydania, trwałe lokalizacje, bezpieczne retry, rollback konfiguracji, przerwanie wieloplikowego apply oraz zakres wersji legacy. Ustalić, jak dowieść braku nierozliczonej pracy i zatrzymania konkretnego starego MCP bez skanowania rozmów Codexa. Pokazać, jak blokowany jest start rundy między inspekcją a końcem migracji, i co oznacza pending. Rozliczyć stare locki i feature bez locka, foreign/corrupt DB, wyłączony projekt i inherited worktree. Zidentyfikować faktyczne tabele/stany legacy, nie traktować bound manager jako aktywnego zadania. Przygotować małe syntetyczne przykłady rezultatów i planu migracji. Nie tworzyć nowego brokera ani pełnej maszyny stanów.
