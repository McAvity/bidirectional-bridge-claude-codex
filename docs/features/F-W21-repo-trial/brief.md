# F-W21-repo-trial: one real repository task through hcom

Deliver the bounded stderr fixture correction and evaluate whether feature-execute
can delegate, receive, review and, if needed, correct it through one hcom session.
The executable scope, budget and checks are in the
[trial procedure](../../tasks/hcom-repository-trial.md).

Acceptance evidence: exact stderr bytes and exit code, focused suite, committed
delivery/ledger, independent coordinator review and correlated hcom receipt.
Record process friction and limitations; do not infer general production readiness.
F-W21-hcom-mvp remains accepted and unchanged. This trial has its own execution state.
