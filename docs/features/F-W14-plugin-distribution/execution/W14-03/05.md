## Disposition

### W14-R2-07 — the pre-journal boundary

**Reproduced** at `dabaf19…` against the shipped pin `ba4025b1…`. Killing the process immediately
*after* the `.bridge-runtime` mkdir returns leaves an empty local directory and a valid own native
marker; the restart refused:

```
2_after_mkdir  dir=True pend=False rec=False marker=True | read=False recovered=False
SETUP_STATE_PARTIAL: … has partial state that is not this worktree's own: unexplained
```

The gate defined a recoverable reservation as `!existsSync(local.dir) && native.kind === "own"`, so
the mere existence of the directory discarded the same valid native evidence that made the
*before*-mkdir case recover.

**Fixed** by replacing the accumulated per-boundary conditions with **one rule**, as the review's
step-back required — a simplification rather than another special case:

> A worktree may finish preparing itself when its local state is *explained* as its own and nothing
> *contradicts* that explanation.

*Explained* is one of the two records this worktree writes about itself: the selection journal or
the runtime's own state marker. *Contradicted* is either of those naming another worktree or being
unreadable, or a `.bridge-runtime/current` that is not a symlink. The bare existence of the
directory is neither, because an interrupted apply creates it before writing into it; unknown files
inside it are neither, and the plan never removes them. Nothing else is waived: foreign or invalid
records, pin mismatches, symlinked managed paths, the native identity guard and the ordinary
conflict rules all still apply, above the rule and inside `planChange`. Recovery still happens only
at the next authorised mutation, through the existing guarded plan.

**Proven** against the refreshed pin at five interruption points — before the directory exists,
immediately after it is created, after the journal and before the selection, after the selection,
and after the record. Each restart serves reads with a byte-identical tree and no setup command, and
the following authorised mutation completes the preparation and leaves no journal behind.
