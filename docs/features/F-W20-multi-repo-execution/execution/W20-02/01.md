## Problems and resolutions

- The first run of the helper tests had 3 failures:
  - `git rev-list -z` leaves newlines in the commit list, so the helper now uses a whitespace split;
  - collision detection depended on entry order, because only already-seen entries were compared;
    it now compares every other entry and the parent;
  - a test assumed the delivered commit was not on `main` after merging it, which was the test's
    own error, so it now uses an unmerged commit.

  After the fixes: 25/25.
- `generate.mjs` is outside the write scope. Its generic `.agents/skills/` rewrite and whole-skill
  copy already ship `scripts/multi_repo.py` and resolve the instruction paths. The existing guard
  against a shipped `def receipt(` (wave16 transcription) is respected: the receipt function is
  named `check_receipt`.
