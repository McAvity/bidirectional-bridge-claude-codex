## Limitations

1. **No model, no pilot, no CI.** Real CLI, real launcher, synthetic executor.
2. **`ENOSPC` is injected at the write primitives**, not produced by a full device; both shapes a
   full disk takes are covered, and `RLIMIT_FSIZE` reaches the same branch through the kernel.
3. **Rotation evidence uses doctor's own subprocess as the sync point**: it proves detection of a
   rename, replacement or unlink between the read and the final check, not every interleaving of a
   concurrent retention pass.
4. **The namespace anchor is the home the namespace came from.** A home that is itself a link is
   the user's own arrangement; everything below it is checked before any write.
5. **Leftover private staging after a hard kill** is possible by design; nothing reads it.
6. **Closed vocabularies** mean a package from a newer runtime reports an unknown state or code as
   `"invalid"`; deliberate and documented.
7. **Interleaving the database and the log remains an approximation**: two cutoffs, two clocks.
8. `--with-database` still carries every stored field, including free text; explicit extension.
9. Integration, CI, independent re-review and user acceptance are outside this round.
