## Limitations

1. **No model, no pilot, no CI.** Every scenario uses the real CLI, the real launcher and the
   repository's synthetic executor. Nothing here is real-agent evidence, and this delivery is not
   feature acceptance.
2. **`ENOSPC` is not simulated**; the permission-denied paths exercise the same error branch.
3. **Processes are never inspected** by the export, and a refused call exists only in the stderr
   of the process that refused it — the package reports both as unavailable rather than absent.
4. **Interleaving the database and the log is an approximation.** Two cutoffs, two clocks; only
   `seq`/`mono_ms` within one process and `event_id` within the database are ordered evidence.
5. **Redaction is a guardrail.** The default package withholds content by allowlist, but content
   placed inside an identifier still travels, and `--with-database` deliberately carries
   everything.
6. **The EOF shutdown gap from W13-01 is unchanged**: a session closed by stdin EOF still writes
   no `process.stop`/`log.close`, which the tests assert as evidence rather than repair.
7. Integration into `feature-workflow`, CI, independent review and user acceptance are outside
   this round.
